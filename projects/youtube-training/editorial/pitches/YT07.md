# YT07 — Build a URL Shortener From Scratch (and Break It)

**Format:** practical build walkthrough (V11 card `t-20261015-a491`) · 300–330 s · slot YT07

## Audience and promise

A viewer who can write a little code and has used a short-link service without
wondering how it works. Promise: **in five minutes you will see a real shortener
built from nothing — id encoding, storage, redirect — and then watched failing in
three instructive ways.** The "and break it" half is what makes this a build
*walkthrough* instead of a feature tour.

## Sources (three, one primary)

1. **Primary:** RFC 3986, *Uniform Resource Identifier (URI): Generic Syntax*
   (IETF, January 2005) — what a URI and a redirect target actually are.
   https://www.rfc-editor.org/rfc/rfc3986
2. **Primary:** RFC 9110, *HTTP Semantics* (IETF, June 2022) — the definitions of
   301 Moved Permanently and 302 Found that the film contrasts.
   https://www.rfc-editor.org/rfc/rfc9110
3. OWASP *Unvalidated Redirects and Forwards* — the security failure mode shown
   in "Break it #2", credited on screen.
   https://owasp.org/www-community/attacks/Unvalidated_Redirects_and_Forwards_Cheat_Sheet

## Claim ledger (material claims only)

| # | claim in film | source | where |
|---|---|---|---|
| 1 | A 301 is cacheable and permanent; a 302 is not — with consequences for analytics and for reuse | RFC 9110 §15.4 | 2:20 |
| 2 | base62 with 7 characters allows 62^7 ≈ 3.5×10^12 ids | arithmetic shown on screen | 0:40 |
| 3 | Sequential ids are enumerable | demonstrated on camera, not asserted | 3:00 |
| 4 | Unvalidated redirect targets are a recognised abuse vector | OWASP, credited | 3:50 |

The film states clearly that the code shown is a teaching artefact, not
production software, and lists what it deliberately omits (auth, rate limits,
abuse reporting).

## Rights / asset strategy

Every line of code is written for this film and released under an open licence
noted in the credits. Screen recordings are our own terminal. No third-party UI,
no borrowed screencasts, no logos.

## Collision note

Distinct from YT02 (a verification skill, no service built) and YT05 (how a
codec works). YT07's deliverable is a running artefact plus its failure modes.
