Attempt 2 is the stronger evidence: its keys were generated by
`gen_key.py` computing each answer from first principles (Dijkstra,
minimax eval, resolution count, chain marginalisation, one perceptron
epoch), while the answer sheet was written from the problem statements
alone. Two independent derivations agreeing is what a solo agent can
offer in place of a grader; any mismatch would have been a real error.

## Honest caveat (read before trusting the numbers)

The attempt-1 bank was authored by the same agent that sat it, from the
same notes the agent wrote. A 100% there measures internal consistency
of the notes, not mastery against an external examiner. The 85% bar is
cleared, but the score is cheaper than one graded by another agent or by
the course's own materials; anyone reviewing should spot-check two or
three bank questions against the MIT sources, not against these notes.
No weak section was produced, so no revisit round exists to show — the
rule's revisit clause is satisfied vacuously, and that is stated rather
than papered over.

## Files

- bank.json — 30-question bank (MC + numeric), with answers.
- bank-b.json — 5 blind numeric questions; keys mirror gen_key.py output.
- gen_key.py — independent key computation (deterministic).
- answers-attempt1.json / answers-attempt2.json — the answer sheets.
- quiz.py — the grader; exit 0 iff bar met everywhere.
