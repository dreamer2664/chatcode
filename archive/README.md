# archive/ — history, never instructions

- `docs-v3/` — the manuals that came before AGENCY.md (START_HERE, WORKER, MANAGER,
  START_HERE_MANAGERS, PROTOCOL, SYSTEM, AGENT_PROMPT, STORAGE, INVENTORY).
  They are kept for the record. They are not law. Where they disagree with
  `AGENCY.md`, AGENCY.md wins.
- `board/` and `bus/` archives live where they always did (`board/archive/`,
  `bus/archive/`), so the append-only rule holds.

Why the cut: every policy change used to mean re-minting five documents, and the
five drifted out of sync — a new agent had to guess which file was true. One law
file with an EPOCH line, and job briefs that reference it, is the fix.
